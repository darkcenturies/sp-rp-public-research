# doctor-valkyrie crash rules - Project Eagle
#
# Format is CrashInfo's, so the MixMods community list (CrashList.txt) works
# alongside this file unchanged. Blocks are separated by blank lines.
#
#   Error:    crash address, as printed in the log. Several may be listed.
#   Library:  matches "Last library loaded"
#   File:     matches "Last file loaded"
#   Module:   matches the module the crash address is inside
#   Code:     matches the exception code
#   Problem:  what is wrong          (printed to the player)
#   Solution: what to do about it    (printed to the player)
#
# A rule matches when every key it declares matches, and the rule that matched
# the most keys wins. That is why a rule here with File: + Error: beats the
# community list's entry for the same address - ours knows it is Project Eagle.
#
# Every rule below was derived from crash logs posted in #bugs-problems, and
# the fix in each was confirmed by the person who reported it. Where a fix was
# only partial, the rule says so rather than pretending.

Error: 0x00749B7B
Problem: Una función de script o juego trató de utilizar un modelo o archivo que no estaba cargado o no existía cuando se le solicitó. La línea de último archivo puede mostrar streaming de fondo no relacionado, por lo que no necesariamente nombre el modelo perdido.
Solution: Reproduce la acción e identifique el modelo solicitado por el script, entrenador, misión o objeto desovedo inmediatamente antes. Asegúrese de que el modelo está registrado y cargado antes de que la función lo use. Esta dirección puede tener otras causas, así que conserva el informe completo y compara el historial de archivos si cargar el modelo esperado no lo arregla.

Error: 0x49646550
Problem: Probablemente el juego no pudo recuperar un objeto, modelo o textura de la carpeta del juego. Esta dirección aún no se comprende por completo: también apareció junto a errores antiguos de scripts de misión, por lo que Doctor no puede atribuirle honestamente una única causa.
Solution: Conserve el informe completo y anote la misión o acción inmediatamente anterior al fallo. Compruebe que los modelos y texturas relacionados existan y estén registrados. Compruebe también que ENHI (Enterable Hidden Interiors) no se haya instalado sobre Project Eagle. En Propiedades de gta_sa.exe, pruebe «Ejecutar como administrador» y configure la sustitución del ajuste de PPP alto como «Aplicación». Históricamente también se sugirió Windows DEP, pero no desactive la protección de todo el sistema por un diagnóstico no confirmado. Se necesitan más informes reproducibles para distinguir entre un recurso ausente y un error lógico del script.

Error: 0x006E3D9C
Problem: El juego encontró un problema en una animación o grupo de animaciones, a menudo durante la última acción realizada, como entrar, salir o utilizar un vehículo.
Solution: Anote la acción y el modelo exactos inmediatamente anteriores al fallo y envíe el informe completo a los desarrolladores de Project Eagle. El grupo de animaciones relacionado puede faltar, ser inválido o incompatible; pruebe sin scripts ni mods que cambien animaciones antes de atribuir el fallo al juego base.

Error: 0x004DD5A3
File: BANKSLOT.DAT
Problem: Project Eagle no está instalado en la parte superior de GTA San Andreas 1.0. Esto no es un problema de audio, a pesar del nombre de archivo - BANKSLOT.DAT vive en la carpeta AUDIO, pero lo que significa es que el juego debajo del mod es la versión incorrecta o es incompleto.

Aproximadamente 13,7 MB corresponde a la versión 1.0 correcta; 5 MB corresponde a una versión posterior incompatible; y 80 MB corresponde a Definitive Edition, que usa otro motor y nunca podrá ejecutar este mod. Si no tiene la versión 1.0, use https://github.com/xxanqw/gtasa-open-downgrader y no permita que instale «Essential Modifications», porque Project Eagle ya las incluye y las copias duplicadas causan fallos. Después copie Project Eagle sobre el juego limpio y sustituya los archivos cuando se le solicite. Project Eagle no funciona por sí solo: incluye un .exe parcheado, no el juego completo. Necesita todos los archivos de un GTA SA 1.0 limpio; no puede ser un repack porque estos modifican los archivos base. Por último, cambie el nombre de la carpeta (por ejemplo, «Grand Theft Auto Project Eagle») para impedir que Steam la actualice y vuelva a dañarla.
