Error: d3d9.dll
Problem 1: Es el .dll usado para muchas cosas, pero principalmente gráficos rendering cosas relacionadas. Puede ser algún fallo relacionado con efectos gráficos, modelos u otro mod gráfico que utiliza este dll, pero también hay mods que se hacen utilizando este dll, mods super viejos de la versión GTA SA donde terminaron utilizando este .dll para crear el mod , completamente obsoleto ahora, dejar de usar estos mods. Si no utiliza serie enb u otros mods de este dll, debe ser corregido actualizando su DirectX Runtime, y luego, si tiene este dll instalado en su juego, eliminarlo (o no).
Problem 2: Si se estrelló en una misión, extrañamente este dll puede chocar y la solución enviada por Luiz Felipe dice que simplemente tienes que saltar el cutscene pulsando Enter. Puede ser causado por una capción de buggy u otro texto en la pantalla, generalmente por traducciones o mods, en este caso, es mejor ponerse en contacto con el creador y / o deshabilitar las capciones o saltar el cutscene si es posible. La traducción de Gamevicio tiene este accidente, nuestra traducción pt-br no.
Problem 3: Si un fallo en el menú avanzado de los gráficos del juego y usted está utilizando 90 AVP Reborn, fue causado por su Super GT y la solución es simplemente para cambiar este coche. De la misma manera es posible que no estés usando los 90 AVP pero podrías tener este mismo coche, u otro coche con el mismo problema, es decir, si este dll se estrella en este menú, podría ser un coche instalado en tu GTA.
Problem 4: ¿Durante una explosión? ¿Usando algún mod como Remastered Effects? Si tiene 0x007FDE14 y/o 0x007FE7DC y/o 0x004A140A en el "Backtrace" al final del registro, puede ser causado por IgnoreWater de MixSets (o incluso FreezeHour). Así que, si está habilitado, establece estas funciones a -1 en MixSets.

Error: ntdll.dll
Problem: Dificultad para conocer la razón exacta ya que es un Windows .dll muy común. Pero es más probable que tenga algo que ver con subir archivos.
En primer lugar, si el accidente ocurrió al abrir el juego, simplemente trate de abrirlo una o dos veces más que debería funcionar. Es raro y todavía no sé por qué. Pero este mismo error puede ser causado por otras cosas:
Solution 1: Al final de "modloader.log", en la línea superior de la dirección de bloqueo, tendrá el último archivo leído, por ejemplo: "Cargando tipos de objeto predeterminados "data\maps\veh_mods\veh_mods.ide"", en este ejemplo, posiblemente se estrelló al intentar leer el archivo veh_mods.ide, compruébelo. Si el último archivo era un .txd, posiblemente no era un problema con él. También a menudo no puede tener nada que hacer, como por ejemplo, si entras en una tienda aparecerá que "shopping.dat" fue cargado por última vez, pero eso no significa que el accidente estaba en este archivo también, así que ten cuidado no seguro, pero todavía tratar de comprobarlos, especialmente si el accidente fue cuando trató de abrir el juego.
Solution 2: Compruebe los permisos y lecturas de archivos de Windows, puede ser cualquier archivo, ya sea desde la carpeta de datos o desde algún mod. Siempre recomiendo usar GTA en Documentos y no Archivos del Programa, solucionar este y otros problemas.
Solution 3: Si se estrelló al seleccionar la radio "User Tracks", actualice su versión CLEO, este fallo ya estaba fijo, o elimine el archivo "sa-utrax.dat" de la carpeta "Documentos/GTA San Andreas User Files". También es posible que algunos .mp3 hay con la codificación incorrecta, GTA SA sólo acepta el formato MP3 LAME.
Solution 4: Si el SAMP se estrelló, compruebe si "SAMP Fix" está marcado en el ImVehFt .ini. O si faltan archivos necesarios para que SAMP funcione (en este caso la reinstalación de SAMP ayudará)
Solution 5: Si ve seguido por una ventana de error "std.asi: traductor. SteupASI no identificó la llamada ASI", es porque era incompatibilidad de uno .asi con otro, mods .asi que modifica lo mismo que el otro. Creo que esto fue una vez debido a vehlightsfix.asi junto con silentpatch.asi, ya que ambos arreglan algunas de las mismas cosas, pero eso fue sólo una conjetura y también un ejemplo.
Problem 6: Action_x86.dll incompatible con ntdll.dll.
Solution 6: Cambiar a resolución de color de 32 bits.
Problem 7: ¿Al entrar en un interior? Según Luiz Felipe, posiblemente utilice el mod HiDefCam.asi, tomó una foto con la memoria de streaming (memoria corriente) en el límite y luego entró en un interior donde causó el accidente.
Solution 7: Desinstalar HiDefCam.asi.
Problem 8: ¿Después de minimizar el juego?
Solution 8: Pausa el juego antes de minimizar, o si ya lo has pausado, podría ser el mod SAGrading (colorcycle).
Solution 9: Intente instalar el Fastloader mejorado.
Solution 10: El archivo stream.ini falta en la carpeta del juego.
Solution 11: No utilice caracteres especiales (sin punción, etc) en el nombre de la carpeta del juego o en algún lugar a lo largo de la ruta. También no vayas demasiado tiempo. Ya se ha fijado después de eliminar caracteres [ y . del nombre de carpeta del juego, pero no se sabe exactamente si este era el problema, o si el camino era demasiado largo, o si era algún error de Windows, etc.
Solution 12: Si fue durante las pistas de usuario: Vaya a "Documents\ZXQ1QXZ User Files\User Tracks" y compruebe los archivos de música dañados o cualquier otro archivo que no sea el formato mp3. También trate de instalar el nuevo reproductor de medios de Windows de "Añadir o quitar características" o el sitio web de Microsoft.
Solution 13: Skin Selector puede causar aleatoriamente un error leyendo el archivo .img al abrir el juego, sólo abrirlo de nuevo y no causará el problema, todavía no se sabe exactamente qué causa esto.
Solution 14: Usted tiene cualquiera de los siguientes archivos en ModLoader que no siguen la dirección como está en la carpeta original (original ModLoader problema?): datos/gridref.dat; datos/Decision/PedEvent.txt; datos/Paths/ROADBLOX.DAT; modelos/coll/peds.col
