# SA-MP IDA research databases

Published at the owner's request on 12 September 2026. This archive preserves nine locally downloaded databases from [dashr9230/SA-MP](https://github.com/dashr9230/SA-MP). Byte sizes, SHA-256 checksums and provenance are in [manifest.json](manifest.json).

The upstream README identifies client 0.3.7 R5-1 and server 0.3.7 R3 inputs; do not label every database R3. The recorded reference revision is cd3ec8b7ba297ca02402c7f22699dfd5e72e20bd.

IDA databases can retain analyzed binary bytes, original paths, inferred names/types and comments. They are research artifacts, not original vendor source or proof of a rebuildable client. No completeness claim is made for CCustomModels or SAA functions. No additional standalone input executables are copied here.

Credits remain with SA-MP and the upstream researchers. These third-party-derived artifacts are not relicensed under the repository's BSD license; no additional upstream license grant is asserted.
